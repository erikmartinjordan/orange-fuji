Downloads are computed live from the public releases (real installers: .dmg, .zip, .exe, .AppImage). GitHub does not expose per-day download history, so the daily bars are estimated by spreading each release's downloads across the days since it was published. Active-user figures come from optional anonymous daily pings sent by the app (a random device ID, app version and OS, stored only as a salted hash) and can be turned off in Settings. If the API is rate-limited, sample data is shown instead.
