Metrics are computed live from the public releases and repository. The headline download count includes only real installers (.dmg, .zip, .exe, .AppImage); the "all assets" figure matches GitHub's total-downloads badge and also counts updater metadata (.yml, .blockmap). GitHub does not expose per-day download history, so trends are shown per release. Active-user figures come from optional anonymous daily pings sent by the app (a random device ID, app version and OS, stored only as a salted hash) and can be turned off in Settings. If the API is rate-limited, sample data is shown instead.
